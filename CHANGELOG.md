# Changes

## 1.1.0 (2026-08-12)

Small theme update.

- Removed the bottom padding from the summary progress component, this is now handled with spacing
  tokens in its parent(s).

## 1.0.0 (2026-08-07)

Breaking changes release.

The design tokens are now designated as "stable". Many custom tokens have been replaced or removed
in favour for NL Design System community component tokens.

The 1.0 release is mostly to signal that Open Forms versions older than 4.0 should _not_ upgrade to
this package version. This remains an internal package, without strict application of semantic
versioning.
